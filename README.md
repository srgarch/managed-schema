# Sitecore XP Campaigns for Developers: One Simple Step to Make Your Client Happy

## Overview

This repository contains the source code and related materials for the following article:
[https://serg-at.medium.com/sitecore-xp-campaigns-for-developers-one-simple-step-to-make-your-client-happy-ede99bf4019e](https://serg-at.medium.com/sitecore-xp-campaigns-for-developers-one-simple-step-to-make-your-client-happy-ede99bf4019e)

## Installation

### Option 1 — Install via Release Package

Download and install a package from the [repository releases](https://github.com/srgarch/share-buttons-campaign/releases).  
The package includes all required files, items, DLLs, and views, so downloading the source code is not necessary.

### Option 2 — Install from Source Code

Download the source code and configure the publish settings to target your Sitecore instance.  
After publishing, create the required renderings and content items, then attach them to the appropriate pages.

## Testing

After installation, navigate to the `/share-campaigns` page on your website. Example:

```txt
https://sc1041.sc/share-campaigns
```
